Qo‘shimcha vazifa: API kirish

API

Petrolog tahlillarini boshqa dasturlardan chaqirish uchun ochiq interfeys. Asosiy talab: API orqali olingan natija ham dastur ichidagi kabi tekshirib bo‘ladigan bo‘lishi kerak.

Holat: rejalashtirilgan. Dastur FastAPI ustida qurilgan, shuning uchun API yangi arxitektura emas — mavjud funksiyalarni tashqariga ochish. Ommaviy API onlayn versiya bilan birga ishga tushadi (yo‘l xaritasining 5-bosqichi). Quyidagi tuzilma va namunalar shu rejaning hujjati.

Javob tamoyili

Har bir javobda to‘rt narsa bo‘ladi: natija, uning dalil holati (o‘lchangan, kuzatilgan, talqin yoki aniqlab bo‘lmaydi), manba (qaysi tasnif yoki qoida qo‘llangani) va dastur versiyasi. Shunda natijani keyinchalik qayta tiklash va tekshirish mumkin.

Kirish va xavfsizlik

  • Kirish shaxsiy API kaliti orqali; so‘rovlar soni cheklanadi.
  • Yuborilgan tasvir va jadvallar natija qaytarilgach serverda saqlanmaydi.
  • Institutlar uchun API’ni o‘z serverida ishga tushirish mumkin — kod ochiq (AGPL-3.0).
  • Avtomatik hujjat FastAPI tomonidan OpenAPI formatida yaratiladi.
